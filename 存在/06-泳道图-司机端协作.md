# 司机端协作横向泳道图

> Mermaid 原生不支持跨职能真泳道，下方用 `graph LR` + 每个角色一个 subgraph 横向排布，模拟横向泳道：每一列是一个角色（泳道），列内节点是该角色的动作，跨列箭头表示调用/依赖。

```mermaid
%%{init: {
  "theme": "base",
  "themeVariables": {
    "background": "#ffffff",
    "primaryColor": "#e8f0fe",
    "primaryTextColor": "#1a1a1a",
    "primaryBorderColor": "#4285f4",
    "lineColor": "#555555",
    "textColor": "#1a1a1a"
  }
}}%%
graph LR
    classDef app fill:#e8f0fe,stroke:#4285f4,stroke-width:2px,color:#1a1a1a;
    classDef api fill:#fef7e0,stroke:#f9ab00,stroke-width:2px,color:#1a1a1a;
    classDef dr fill:#e6f4ea,stroke:#34a853,stroke-width:2px,color:#1a1a1a;
    classDef rds fill:#fce8e6,stroke:#ea4335,stroke-width:2px,color:#1a1a1a;
    classDef ord fill:#f3e8fd,stroke:#a142f4,stroke-width:2px,color:#1a1a1a;
    classDef kfk fill:#eeeeee,stroke:#999999,stroke-width:2px,color:#666666;

    subgraph LANE1[司机APP 泳道]
        direction TB
        A1["登录拿JWT"]:::app
        A2["上线"]:::app
        A3["心跳/位置上报"]:::app
        A4["接单/行程/完单"]:::app
        A5["下线"]:::app
    end

    subgraph LANE2[API网关 泳道]
        direction TB
        B1["鉴权JWT"]:::api
        B2["转发 online"]:::api
        B3["转发 heartbeat+互踢"]:::api
        B4["聚合 dispatches"]:::api
        B5["转发 order 状态"]:::api
    end

    subgraph LANE3[driverRPC 泳道]
        direction TB
        C1["Login 签发"]:::dr
        C2["SetDriverOnline"]:::dr
        C3["Heartbeat 判定"]:::dr
        C4["SetDriverServiceStatus"]:::dr
    end

    subgraph LANE4[Redis 泳道]
        direction TB
        D1["写在线Hash+TTL"]:::rds
        D2["续期 TTL"]:::rds
        D3["状态 2/1 切换"]:::rds
    end

    subgraph LANE5[订单服务 泳道]
        direction TB
        E1["AcceptOrder"]:::ord
        E2["StartTrip"]:::ord
        E3["FinishTrip"]:::ord
    end

    subgraph LANE6[kafka 泳道 未落地]
        direction TB
        F1["位置事件 TODO"]:::kfk
    end

    A1 --> B1
    B1 --> C1
    A2 --> B2 --> C2 --> D1
    A3 --> B3 --> C3 --> D2
    A4 --> B5 --> C4 --> D3
    A4 --> B5 --> E1
    A4 --> B5 --> E2
    A4 --> B5 --> E3
    B4 --> E1
    A3 -.规划.-> F1
```

## 看图说明
- 六条横向泳道从左到右：司机APP → API网关 → driverRPC → Redis → 订单服务 → kafka。
- 每条泳道内用 `direction TB` 让节点纵向排列，整体呈"列=泳道、行=时序"的横向泳道观感。
- 跨泳道箭头表示调用关系（实线=已落地调用，虚线=规划中）。
- kafka 标灰 TODO：位置变更事件实训阶段未接入。
- 真实带泳道横条的图可用 draw.io 照此结构重画。
