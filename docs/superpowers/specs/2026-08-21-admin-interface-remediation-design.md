# 管理后台接口问题修复设计

## 背景与范围

本设计修复管理后台已审查确认的五项问题，适用范围仅为 `api/admin`、`rpc/adminsvc`、后台接口文档和既有 SQL 迁移说明。不得修改数据库结构、不得执行迁移、不得写入业务数据。

修复目标：

1. 导出任务必须严格应用创建时保存的筛选条件。
2. 已提交业务操作的审计失败不得让客户端误判业务失败；必须记录可补偿审计任务。
3. 统计接口的城市参数必须在具备城市归属的指标中生效。
4. 活动发布和回滚必须遵守状态机与参数约束。
5. 优惠券状态定义必须在数据库迁移说明和接口文档中一致。

## 架构与数据流

HTTP 网关保持现有职责，仅解析参数、校验会话并调用 `adminsvc`。不扩展 HTTP 路径、JSON 字段或 protobuf 契约。

`adminsvc` 新增内部辅助函数以隔离以下逻辑：

- 解析和校验导出 `filters` JSON，并按导出类型映射为白名单 SQL 条件。
- 对同库写操作使用同一 SQL 事务写入业务记录与 `admin_operation_log`。
- 对已提交或跨服务写操作，在审计失败时写入 `admin_audit_outbox`；outbox 写入成功时接口仍返回成功，outbox 写入失败时返回错误。
- 校验活动发布范围、目标配置和合法状态转换。
- 组合按城市和时间的统计 SQL 条件。

导出任务创建时校验筛选条件，后台任务读取同一份已验证 JSON 并生成对应 CSV。筛选条件不会被拼接为原始 SQL，所有值均使用占位参数。

## 业务规则

### 导出

支持的导出类型维持 `users`、`drivers`、`orders`、`operation_logs`、`statistics`。

- `users`：`keyword`、`status`、`start_time`、`end_time`。
- `drivers`：`keyword`、`audit_status`、`start_time`、`end_time`。
- `orders`：`keyword`、`status`、`user_id`、`driver_id`、`start_time`、`end_time`。
- `operation_logs`：`admin_id`、`module`、`action`、`target_type`、`target_id`、`start_time`、`end_time`。
- `statistics`：`city_code`、`start_time`、`end_time`。

筛选 JSON 不允许未知字段。时间必须使用 `YYYY-MM-DD HH:mm:ss`，结束时间必须晚于开始时间。每类导出继续最多导出 5000 行，防止后台 goroutine 无限制占用资源。

### 审计

同库事务操作中，业务表和操作日志共同提交或回滚。已提交的跨服务操作及无法与业务表共用事务的操作，审计写入失败时创建 `admin_audit_outbox`。补偿任务创建成功时接口返回成功，日志问题由后续补偿处理；补偿任务也创建失败时接口返回错误并保留上下文。

### 统计

`city_code` 非空时，订单和支付类指标按订单所属城市过滤。没有可用城市字段的用户、司机、优惠券和黑名单总量保持全局指标，避免错误地将全局数量标注为城市数量。

### 活动

活动仅允许以下转换：

- 发布：`1`（未开始/草稿）到 `2`（运行中）。
- 回滚：`2`（运行中）到 `1`（未开始/草稿）。

发布范围限定为 `gray` 或 `full`；目标配置必须是合法 JSON。状态不满足转换规则时返回 `FailedPrecondition`，HTTP 映射为既有参数错误响应。

### 优惠券状态

统一使用 `1=草稿`、`2=启用`、`3=停用`。仅修订迁移文件中的字段说明与接口文档，不执行任何数据库变更。

## 测试与验收

新增或更新 sqlmock 单元测试，覆盖：

1. 含订单状态和时间范围的导出任务仅查询相应数据。
2. 未知导出筛选字段与非法时间范围在任务创建阶段被拒绝。
3. 已提交业务操作的审计失败会写入 outbox 并返回成功；outbox 失败返回错误。
4. 城市统计 SQL 带有城市过滤条件。
5. 活动状态转换和发布参数的合法/非法路径。
6. 执行 `go test ./api/admin/... ./rpc/adminsvc/...`，使用仓库内独立 `GOCACHE`。

## 非目标

- 不新增下载接口、对象存储、异步补偿消费者或定时清理任务。
- 不为用户、司机、优惠券和黑名单引入新的城市字段。
- 不更改数据库表结构、现有路由、protobuf 字段或 RBAC 权限矩阵。
