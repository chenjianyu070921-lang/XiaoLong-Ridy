# 司机端 API 接口文档（api/driver）

> 服务地址：`http://127.0.0.1:8082`
> 下游 RPC：`driversvc`（gRPC `127.0.0.1:8080`）、`ordersvc`（gRPC `127.0.0.1:50051`）
> 统一响应体：`{ "code": 0, "message": "success", "data": {...}, "timestamp": 0, "traceId": "" }`
> 错误约定：入参校验失败返回 HTTP 400 + `code=50000`；未登录返回 401；账号封禁返回 403。

---

## 一、认证相关（无需登录）

### 1. 发送登录短信验证码
`POST /api/driver/v1/auth/send-sms-code`
```json
{ "phone": "13800000000" }
```
响应：`{ "success": true, "expireIn": 300 }`（联调阶段验证码打印于服务端日志）

### 2. 手机号 + 密码登录
`POST /api/driver/v1/auth/login-by-password`
```json
{ "phone": "13800000000", "password": "abc123" }
```
响应：`{ "token": "<JWT>", "expireIn": 7200, "driver": { "id": 1, "phone": "138****0000", "status": "DRIVER_STATUS_NORMAL" } }`

### 3. 手机号 + 验证码登录
`POST /api/driver/v1/auth/login-by-sms`
```json
{ "phone": "13800000000", "code": "123456" }
```

## 二、司机注册与创建（核心拆分）

### 4. 司机自注册（公开，无需登录）
`POST /api/driver/v1/drivers/register`

> 司机 App 注册入口。底层调用 `driversvc.RegisterDriver`，状态默认 `DRIVER_STATUS_PENDING`（待审核）。
> 密码字段 `password` 由前端传**明文**，后端 RPC 层统一做 **MD5** 加密后存储（加密职责在后端，前端不接触哈希）。

请求：
```json
{
  "phone": "13800000000",
  "password": "abc123",
  "realName": "张三",
  "idCardNo": "110101199001011234",
  "driverLicenseNo": "DL10000001",
  "avatarUrl": ""
}
```
校验规则（API 层 + gRPC 层双校验）：手机号格式、姓名非空、身份证 17 位+校验位、驾驶证号非空。

响应：
```json
{ "id": 25, "status": "DRIVER_STATUS_PENDING", "createdAt": 1787143766 }
```

### 5. 管理员创建司机（需登录）
`POST /api/driver/v1/drivers`

> 后台/运营侧主动建号。底层调用 `driversvc.CreateDriver`，状态默认 `DRIVER_STATUS_PENDING`。
> 与「注册」的区别：注册是司机自助、公开；创建是管理员操作、需 JWT 鉴权。

请求 / 响应字段同「注册」一致（`CreateDriverRequest` / `CreateDriverResponse`）。

### 6. 更新司机
`POST /api/driver/v1/drivers/update`（需登录）
```json
{ "id": 25, "status": "DRIVER_STATUS_NORMAL" }
```
除 `id` 外字段均为可选（指针缺省表示不更新）。

### 7. 查询司机详情
`GET /api/driver/v1/drivers/get?id=25`（需登录）
响应：`data.driver` 含脱敏手机号、身份证、状态等。

### 8. 删除司机（软删）
`POST /api/driver/v1/drivers/delete?id=25`（需登录）
响应：`{ "id": 25, "success": true }`

## 三、上下线与心跳（需登录）

### 9. 司机上线
`POST /api/driver/v1/drivers/online`
```json
{ "deviceId": "dev-001", "longitude": 116.40, "latitude": 39.90 }
```
响应：`{ "driverId": 25, "onlineStatus": 1, "kicked": false }`

### 10. 司机下线
`POST /api/driver/v1/drivers/offline`
```json
{ "deviceId": "dev-001", "longitude": 116.40, "latitude": 39.90 }
```
响应：`{ "driverId": 25, "onlineStatus": 0, "kicked": false }`

### 11. 心跳上报（多端互踢）
`POST /api/driver/v1/drivers/heartbeat`
```json
{ "deviceId": "dev-001", "longitude": 116.40, "latitude": 39.90 }
```
响应：`{ "onlineStatus": 1, "kicked": false, "serverTime": 1787143766 }`
> `kicked=true` 表示被新设备顶替，需重新登录。

## 四、资质相关（需登录）

### 12. 资质上传
`POST /api/driver/v1/drivers/certification/upload`
```json
{
  "vehicleId": 0,
  "idCardFront": "<base64>",
  "idCardBack": "<base64>",
  "driverLicense": "<base64>",
  "vehicleLicense": "<base64>"
}
```

### 13. 资质查询
`GET /api/driver/v1/drivers/certification`
响应：`{ "certification": {...}, "found": true }`

## 六、订单行程（需登录，driver_id 取自 JWT）

| 接口 | 路径 | 说明 |
|------|------|------|
| 接单 | `POST /api/driver/v1/orders/accept` | 推进订单 待接单→已接单 |
| 拒绝派单 | `POST /api/driver/v1/orders/reject` | TODO：待 dispatchsvc 提供 `RejectDispatch`，当前仅完成鉴权与参数解析，返回 501 |
| 我的派单列表 | `POST /api/driver/v1/orders/dispatches` | TODO：待 dispatchsvc 提供按 `driver_id` 查询能力，当前仅完成鉴权与分页参数解析，返回 501 |
| 开始行程 | `POST /api/driver/v1/orders/start-trip` | 推进 已接单→行程中 |
| 确认到达 | `POST /api/driver/v1/orders/confirm-arrive` | 写入到达日志 |
| 结束行程 | `POST /api/driver/v1/orders/finish-trip` | 推进 行程中→待支付，上报里程/时长/金额 |

## 七、跨模块对接（driversvc gRPC 契约）

| 调用方 | 调用方法 | 用途 |
|--------|----------|------|
| adminsvc | `ApproveCertification` / `RejectCertification` | 资质审核（地址 `127.0.0.1:8080`） |
| 派单引擎（规划中） | `ListNearbyDrivers` | 附近在线司机查询 |
| 任意模块 | `GetDriverByPhone` / `GetDriver` / `ListDrivers` | 司机信息查询 |

> 所有接口入参校验在 **API 层（api/driver）与 gRPC 层（driversvc）双重执行**，非法请求不会穿透到存储层。

> 司机端派单相关接口暂不调用 dispatchsvc：依赖补齐前，接口返回 HTTP 501、业务码 `50003`，不会伪造成功响应。

列表请求体：
```json
{ "page": 1, "pageSize": 20 }
```
