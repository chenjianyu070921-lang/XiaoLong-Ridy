# 司机端 API 接口文档

## 1. 基础约定

- 服务地址：`http://127.0.0.1:8082`
- 请求前缀：`/api/driver/v1`
- 需要登录的接口携带：`Authorization: Bearer <JWT>`。
- 成功响应统一为：`{"code":0,"message":"success","data":{},"timestamp":0,"traceId":""}`。
- 参数错误通常返回 HTTP `400`，未登录返回 `401`，账号被冻结或注销返回 `403`。
- `phone` 为中国大陆手机号：`1[3-9]xxxxxxxxx`。
- `password` 为明文传输字段，仅用于本次请求；服务端使用 bcrypt 哈希后存储，密码长度必须为 `8~72` 字节。客户端不得传 `passwordHash` 或 MD5。
- 身份证号要求 18 位：前 17 位数字，末位为数字或 `X/x`。
- 新客户端应使用驼峰字段：`realName`、`idCardNo`、`driverLicenseNo`、`avatarUrl`。为兼容已发布前端，注册接口也暂时接受对应下划线字段；旧 `password_hash` 会被作为明文密码重新 bcrypt。
- 新建司机状态固定为 `DRIVER_STATUS_PENDING`（待审核）。

## 2. 认证接口

### 2.1 发送登录验证码

`POST /api/driver/v1/auth/send-sms-code`（无需登录）

请求：`{"phone":"13800000000"}`

响应 `data`：`{"success":true,"expireIn":300}`。联调阶段验证码写入服务端日志。

### 2.2 密码登录

`POST /api/driver/v1/auth/login-by-password`（无需登录）

请求：`{"phone":"13800000000","password":"Driver@123"}`

响应 `data`：`{"token":"<JWT>","expireIn":7200,"driver":{"id":1,"phone":"138****0000","status":"DRIVER_STATUS_NORMAL"}}`

### 2.3 验证码登录

`POST /api/driver/v1/auth/login-by-sms`（无需登录）

请求：`{"phone":"13800000000","code":"123456"}`。验证码正确且账号未被冻结/注销时返回同 2.2 的登录响应。

## 3. 司机账号

### 3.1 司机自注册

`POST /api/driver/v1/drivers/register`（无需登录）

底层 RPC：`driversvc.RegisterDriver`。

请求：

```json
{
  "phone":"13800000000",
  "password":"Driver@123",
  "realName":"张三",
  "idCardNo":"110101199001011234",
  "driverLicenseNo":"DL10000001",
  "avatarUrl":""
}
```

响应 `data`：`{"id":25,"status":"DRIVER_STATUS_PENDING","createdAt":1787143766}`。

### 3.2 管理员创建司机

`POST /api/driver/v1/drivers`（需要登录）

底层 RPC：`driversvc.CreateDriver`。请求和响应字段与 3.1 相同；当前 HTTP 路由要求有效司机 JWT，管理员角色隔离由上层权限系统负责。

### 3.3 更新司机

`POST /api/driver/v1/drivers/update`（需要登录）

请求：除 `id` 外字段均可选；修改密码时传明文 `password`，服务端重新生成 bcrypt 哈希。

```json
{"id":25,"password":"NewDriver@123","realName":"张三","status":"DRIVER_STATUS_NORMAL"}
```

响应 `data`：`{"id":25,"status":"DRIVER_STATUS_NORMAL","updatedAt":1787143766}`。

### 3.4 查询司机详情

`GET /api/driver/v1/drivers/get?id=25`（需要登录）

响应中的手机号和身份证号已脱敏，不返回密码哈希。

### 3.5 删除司机

`POST /api/driver/v1/drivers/delete?id=25`（需要登录）

执行软删除。响应 `data`：`{"id":25,"success":true}`。

## 4. 在线状态与心跳

以下接口均需要登录，`driverId` 从 JWT 获取，不从客户端传入。

- `POST /api/driver/v1/drivers/online`：请求 `{"deviceId":"dev-001","longitude":116.40,"latitude":39.90}`，返回 `onlineStatus=1`。
- `POST /api/driver/v1/drivers/offline`：请求字段同上线，返回 `onlineStatus=0`。
- `POST /api/driver/v1/drivers/heartbeat`：请求字段同上线，返回 `onlineStatus`、`kicked` 和 `serverTime`；`kicked=true` 表示当前设备已被新设备顶下线。

## 5. 司机资质

- `POST /api/driver/v1/drivers/certification/upload`（需要登录）：上传 `vehicleId` 及不带 data URI 前缀的 Base64 字段 `idCardFront`、`idCardBack`、`driverLicense`、`vehicleLicense`，服务端写入 MinIO 和 `driver_certification`。
- `GET /api/driver/v1/drivers/certification`（需要登录）：返回 `certification` 和 `found`；无记录时 `found=false`。

## 6. AI 推荐分

`GET /api/driver/v1/drivers/ai-score?id=25`（需要登录）

响应包含 `driverId`、`aiScore`、`level`、`factors`、`degraded` 和 `degradeReason`。服务不可用时返回降级标记，不影响其他业务。

## 7. 订单行程

以下接口均需要登录，司机身份从 JWT 获取：

| 接口 | 请求体 | 说明 |
|---|---|---|
| `POST /api/driver/v1/orders/accept` | `{"orderId":1}` | 接单 |
| `POST /api/driver/v1/orders/reject` | `{"orderId":1,"reason":"距离较远"}` | 拒绝派单 |
| `POST /api/driver/v1/orders/dispatches` | `{"page":1,"pageSize":20}` | 查询我的派单 |
| `POST /api/driver/v1/orders/start-trip` | `{"orderId":1}` | 开始行程 |
| `POST /api/driver/v1/orders/confirm-arrive` | `{"orderId":1}` | 确认到达 |
| `POST /api/driver/v1/orders/finish-trip` | `{"orderId":1,"actualDistanceM":1200,"actualDurationS":600,"actualPriceCents":1800}` | 结束行程 |

## 8. driversvc RPC 对接

| HTTP 业务 | RPC 方法 |
|---|---|
| 自注册 | `RegisterDriver` |
| 管理员创建 | `CreateDriver` |
| 更新/查询/删除 | `UpdateDriver` / `GetDriver` / `DeleteDriver` |
| 登录 | `Login` / `GetDriverByPhone` |
| 上下线/心跳 | `SetDriverOnline` / `SetDriverOffline` / `Heartbeat` |
| 资质 | `UploadCertification` / `GetCertification` |
| 推荐分 | `GetDriverAiScore` |

创建和注册使用独立 RPC，但均由 driversvc 统一执行身份字段校验、bcrypt 哈希格式校验和唯一性校验。为兼容历史 gRPC 客户端，`password_hash` 若携带 `8~72` 字节的明文密码，服务端会在入库前自动生成 bcrypt 哈希；新客户端仍应通过 HTTP 接口传递 `password` 明文。
