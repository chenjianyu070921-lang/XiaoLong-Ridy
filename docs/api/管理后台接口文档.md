# 管理后台接口文档

> 适用范围：`api/admin`、`rpc/adminsvc`
>
> 基础路径：`/admin/v1`
>
> 覆盖模块：认证、用户管理、司机审核、订单处理、优惠券配置、计价规则、营销活动、导出任务、风控黑名单、数据统计。
>
> 说明：本文档已对齐当前 `api/admin/internal/handler/router.go`、`rpc/adminsvc/admin.proto` 和路由冒烟测试。未在路由中注册的旧规划接口会明确标注为“未开放路由”。

## 1. 通用规范

### 1.1 鉴权方式

除登录、首次注册外，所有接口都需要携带后台管理员 token。

```http
Authorization: Bearer <token>
Content-Type: application/json
```

### 1.2 统一响应格式

```json
{
  "code": 0,
  "message": "ok",
  "data": {}
}
```

### 1.3 分页参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `page` | int | 否 | `1` | 页码，从 1 开始 |
| `page_size` | int | 否 | `20` | 每页条数，最大建议 `100` |

分页响应结构：

```json
{
  "list": [],
  "total": 0,
  "page": 1,
  "page_size": 20
}
```

### 1.4 通用时间参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `start_time` | string | 开始时间，格式 `YYYY-MM-DD HH:mm:ss` |
| `end_time` | string | 结束时间，格式 `YYYY-MM-DD HH:mm:ss` |

### 1.5 操作审计要求

以下操作必须写入 `admin_operation_log`：

| 操作类型 | 示例 |
| --- | --- |
| 认证类 | 登录、退出、注册管理员 |
| 审核类 | 司机审核通过、司机审核驳回 |
| 状态变更类 | 冻结用户、解冻用户、拉黑、解除黑名单 |
| 资金类 | 退款、补偿、优惠券补发 |
| 配置类 | 创建优惠券、停用优惠券、发布活动、回滚活动 |

`POST /admin/v1/auth/register`

当前状态：已实现。

说明：

`POST /admin/v1/orders/{id}/cancel`

当前状态：已实现。

请求体：

```json
{
  "reason": "司机长时间未接单",
  "remark": "客服核实后取消"
}
```

处理链路：
- `api/admin` 校验 Bearer Token，解析订单 ID、取消原因、管理员 ID、客户端 IP。
- `api/admin` 调用 `adminsvc.CancelOrder`。
- `adminsvc` 同步调用 `ordersvc.CancelOrder`，固定传入 `operator_type=admin`。
- `ordersvc` 负责订单状态机校验、订单取消落库和订单状态日志。
- `adminsvc` 写入后台操作日志。

### 6.2 创建优惠券模板

`POST /admin/v1/coupons`

当前状态：已实现。

请求体：

```json
{
  "name": "新用户立减券",
  "type": 3,
  "face_value": "8.00",
  "discount": "1.00",
  "threshold_amount": "0.00",
  "total_count": 10000,
  "per_user_limit": 1,
  "valid_start_at": "2026-08-13 00:00:00",
  "valid_end_at": "2026-12-31 23:59:59",
  "status": 1
}
```

处理要求：
- 金额字段使用字符串或高精度 decimal，不使用 float。
- 校验有效期、库存、用户领取上限。
- 写入操作日志。

### 6.3 编辑优惠券模板

`PUT /admin/v1/coupons/{id}`

当前状态：已实现。

约束：
- 已发放优惠券不允许随意修改金额、门槛、有效期等核心规则。
- 如需修改核心规则，应创建新版本。

### 6.4 停用优惠券

`POST /admin/v1/coupons/{id}/disable`

当前状态：已实现。该接口将优惠券状态置为停用。

### 6.5 发券

当前状态：已实现。

- 大批量发券后续建议拆成 MQ/job 异步消费。

### 13.1 后台取消订单

`POST /admin/v1/orders/{id}/cancel`

当前状态：P0 已落地，可通过 Postman 调用。

请求体：

```json
{
  "reason": "司机长时间未接单"
}
```

处理链路：

1. `api/admin` 校验 `Authorization: Bearer <token>`。
2. `api/admin` 解析路径订单 ID、请求体 `reason`、管理员 ID、客户端 IP。
3. `api/admin` 调用 `adminsvc.AdminService.CancelOrder`。
4. `adminsvc` 同步调用 `ordersvc.CancelOrder`，固定传入 `operator_type=admin`。
5. `ordersvc` 负责订单状态机校验、订单取消落库和订单状态日志。

响应体：

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "message": "ok"
  }
}
```
