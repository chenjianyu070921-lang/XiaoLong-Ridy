# 管理后台接口文档

> 适用范围：`api/admin`
>  
> 说明：本文档仅覆盖管理后台能力，不包含乘客端和司机端接口。

## 1. 接口总览

- 基础路径：`/admin/v1`
- 鉴权方式：`Authorization: Bearer <token>`
- 返回格式：

```json
{
  "code": 0,
  "message": "ok",
  "data": {},
  "request_id": "xxxxxxxx"
}
```

- 分页参数：
  - `page`: 页码，默认 `1`
  - `page_size`: 每页条数，默认 `20`
- 通用筛选参数：
  - `keyword`
  - `status`
  - `start_time`
  - `end_time`
- 所有敏感操作必须记录 `admin_operation_log`
- 所有状态变更接口必须携带原因字段，如 `reason`、`remark`

## 2. 核心对象

- 管理员：`admin_user`
- 操作日志：`admin_operation_log`
- 用户：`user`
- 用户地址：`user_address`
- 司机：`driver`
- 司机车辆：`driver_vehicle`
- 司机审核：`driver_certification`
- 司机评分：`driver_score`
- 司机提现：`driver_withdraw`
- 订单：`ride_order`
- 订单状态日志：`order_status_log`
- 派单记录：`dispatch_record`
- 计价规则：`price_rule`
- 订单价格：`order_price`
- 支付单：`payment`
- 结算单：`settlement`
- 优惠券模板：`coupon`
- 用户优惠券：`user_coupon`
- 营销活动：`promotion_activity`
- 黑名单：`blacklist`

## 3. 认证与权限

### 3.1 登录

`POST /admin/v1/auth/login`

请求体：

```json
{
  "username": "admin",
  "password": "123456"
}
```

返回字段：

- `token`
- `admin`
- `expires_in`

### 3.2 退出登录

`POST /admin/v1/auth/logout`

说明：使当前 token 失效。

### 3.3 当前管理员信息

`GET /admin/v1/auth/me`

返回字段：

- `id`
- `username`
- `real_name`
- `role`
- `status`

### 3.4 菜单权限

`GET /admin/v1/menus`

说明：按当前角色返回菜单树和按钮权限码。

- `target_type`

- `start_time`
- `end_time`

- `reason`
- `operator_id`
- `status`
- `created_at`

### 9.2 风控说明

- `target_type` 支持 `user`、`driver`、`device`
- 拉黑后，登录、下单、接单前都应执行校验
- 解封后应保留历史记录，不做物理删除

## 13. 交互约定

- 列表页必须支持分页、筛选、搜索、排序
- 详情页优先展示“当前状态 + 状态时间线”
- 审核、冻结、拉黑、停用、取消订单等操作必须二次确认
- 所有高风险操作必须填写原因
- 金额字段统一使用高精度数值类型或字符串，不使用浮点数
- 管理后台不直接修改业务事实，优先通过 RPC 和事件链路完成
