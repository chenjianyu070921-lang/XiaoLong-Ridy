# 管理后台接口文档

> 适用范围：`api/admin`、`rpc/adminsvc`
>
> 基础路径：`/admin/v1`
>
> 覆盖模块：用户管理、司机审核、订单处理、优惠券配置、风控黑名单、数据统计。
>
> 说明：本文档面向管理后台接口设计。已落地的 P0 接口可直接联调；P1/P2 接口用于后续开发对齐。

## 1. 通用规范

### 1.1 鉴权方式

除登录、首次注册外，所有接口都需要携带后台管理员 token。

```http
Authorization: Bearer <token>
Content-Type: application/json
```

### 1.2 统一响应格式

```json
{
  "code": 0,
  "message": "ok",
  "data": {},
  "request_id": "optional-request-id"
}
```

### 1.3 分页参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `page` | int | 否 | `1` | 页码，从 1 开始 |
| `page_size` | int | 否 | `20` | 每页条数，最大建议 `100` |

分页响应结构：

```json
{
  "list": [],
  "total": 0,
  "page": 1,
  "page_size": 20
}
```

### 1.4 通用时间参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `start_time` | string | 开始时间，格式 `YYYY-MM-DD HH:mm:ss` |
| `end_time` | string | 结束时间，格式 `YYYY-MM-DD HH:mm:ss` |

### 1.5 操作审计要求

以下操作必须写入 `admin_operation_log`：

| 操作类型 | 示例 |
| --- | --- |
| 认证类 | 登录、退出、注册管理员 |
| 审核类 | 司机审核通过、司机审核驳回 |
| 状态变更类 | 冻结用户、解冻用户、拉黑、解除黑名单 |
| 资金类 | 退款、补偿、优惠券补发 |
| 配置类 | 创建优惠券、停用优惠券、发布活动、回滚活动 |

## 2. 登录鉴权

### 2.1 管理员注册

`POST /admin/v1/auth/register`

当前状态：已实现。

说明：
- 首个管理员允许免 token 注册。
- 后续管理员注册必须由超级管理员发起。

请求体：

```json
{
  "username": "admin",
  "password": "123456",
  "real_name": "系统管理员",
  "role": 1
}
```

响应字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `token` | string | 登录 token |
| `expires_in` | int64 | token 有效期，单位秒 |
| `admin` | object | 管理员信息 |

### 2.2 管理员登录

`POST /admin/v1/auth/login`

当前状态：已实现。

请求体：

```json
{
  "username": "admin",
  "password": "123456"
}
```

### 2.3 管理员退出

`POST /admin/v1/auth/logout`

当前状态：已实现。

说明：删除 Redis 中的当前 token 会话。

### 2.4 当前管理员信息

`GET /admin/v1/auth/me`

当前状态：已实现。

响应字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | int64 | 管理员 ID |
| `username` | string | 登录名 |
| `real_name` | string | 真实姓名 |
| `role` | int32 | 角色：1 超管，2 运营，3 客服 |
| `status` | int32 | 状态：1 正常，2 停用 |

### 2.5 菜单权限

`GET /admin/v1/menus`

当前状态：已实现。

说明：按当前管理员角色返回后台菜单和按钮权限码。

### 6.1 优惠券模板列表

`GET /admin/v1/coupons`

当前状态：规划接口。

查询参数：

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `keyword` | string | 否 | 优惠券名称 |
| `type` | int32 | 否 | 1 满减券，2 折扣券，3 立减券 |
| `status` | int32 | 否 | 1 草稿，2 启用，3 停用 |
| `start_time` | string | 否 | 创建开始时间 |
| `end_time` | string | 否 | 创建结束时间 |

### 6.2 创建优惠券模板

`POST /admin/v1/coupons`

当前状态：规划接口。

请求体：

```json
{
  "name": "新用户立减券",
  "type": 3,
  "face_value": "8.00",
  "discount": "1.00",
  "threshold_amount": "0.00",
  "total_count": 10000,
  "per_user_limit": 1,
  "valid_start_at": "2026-08-13 00:00:00",
  "valid_end_at": "2026-12-31 23:59:59",
  "status": 1
}
```

处理要求：
- 金额字段使用字符串或高精度 decimal，不使用 float。
- 校验有效期、库存、用户领取上限。
- 写入操作日志。

### 6.3 编辑优惠券模板

`PUT /admin/v1/coupons/{id}`

当前状态：规划接口。

约束：
- 已发放优惠券不允许随意修改金额、门槛、有效期等核心规则。
- 如需修改核心规则，应创建新版本。

### 6.4 启用 / 停用优惠券

`PATCH /admin/v1/coupons/{id}/status`

当前状态：规划接口。

请求体：

```json
{
  "status": 3,
  "reason": "活动结束"
}
```

### 6.5 发券

`POST /admin/v1/coupons/{id}/issue`

当前状态：规划接口。

## 10. 统一错误码

| code | HTTP 状态码 | 说明 | 处理建议 |
| --- | --- | --- | --- |
| `0` | 200 | 成功 | 正常处理 |
| `40001` | 400 | 参数错误 | 前端检查请求参数 |
| `40003` | 403 | 无权限 | 提示无权限或申请权限 |
| `40004` | 401 | token 缺失或失效 | 重新登录 |
| `40401` | 404 | 资源不存在 | 刷新列表或检查 ID |
| `40901` | 409 | 状态冲突 | 重新拉取最新状态 |
| `40902` | 409 | 幂等冲突 | 避免重复提交 |
| `50000` | 500 | 系统异常 | 后端排查日志 |

### 13.1 后台取消订单

`POST /admin/v1/orders/{id}/cancel`

当前状态：P0 已落地，可通过 Postman 调用。

请求体：

```json
{
  "reason": "司机长时间未接单"
}
```

处理链路：

1. `api/admin` 校验 `Authorization: Bearer <token>`。
2. `api/admin` 解析路径订单 ID、请求体 `reason`、管理员 ID、客户端 IP。
3. `api/admin` 调用 `adminsvc.AdminService.CancelOrder`。
4. `adminsvc` 同步调用 `ordersvc.CancelOrder`，固定传入 `operator_type=admin`。
5. `ordersvc` 负责订单状态机校验、订单取消落库和订单状态日志。

响应体：

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "message": "ok"
  }
}
```
