## 四、已通过重点用例

### 鉴权

- 非法请求体 / 空请求体注册、登录 → `400 / 40001`
- 错误密码 → `401 / 40004`
- 未带 token 访问业务接口 → `401 / 40004`
- `GET /auth/me`、`GET /menus`、`POST /auth/logout` → `200 / 0`
- 登出后原 token 再访问 → `401 / 40004`
- 错误方法（`GET /auth/register`）→ `405 / 40001`

### 用户管理

- 用户列表、`page_size=1000` 钳制为 100 → `200 / 0`
- 详情 / 冻结 / 解冻 不存在的用户（999999）→ `404 / 40401`
- 非法路径 ID（`/users/abc`）→ `400 / 40001`

### 司机审核

- 列表与筛选 → `200 / 0`
- 详情 / 通过 / 驳回 不存在的认证（999999）→ `404 / 40401`（driversvc 正确返回 NotFound）

### 订单管理

- 列表、筛选 → `200 / 0`
- 真实订单详情（id=8）→ `200 / 0`（聚合返回订单主信息）
- 详情 404、异常订单列表（全部 / `abnormal_type=cancel`）→ 正常

### 优惠券 / 活动 / 风控 / 导出 / 统计（正向写链路，数据已回收）

- 优惠券：新增（返回新 ID）→ 编辑 → 下架，全部 `200 / 0`
- 活动：新增 → 编辑 → 发布 → 回滚，全部 `200 / 0`
- 黑名单：新增（user/9999998）→ 解除，全部 `200 / 0`；不存在的记录释放 → `404 / 40401`
- 导出任务：创建返回 `task_no`，列表可查 → `200 / 0`
- 统计：运营总览、订单统计、优惠券统计 → `200 / 0`
- 各写接口非法请求体 → `400 / 40001`；不存在的资源编辑/发布/下架 → `404 / 40401`

## 五、2026-08-18 环境阻塞与建议（历史记录）

### 5.1 `rpc/ordersvc` 无法启动（影响后台取消订单）

`rpc/ordersvc/internal/config.Config` 同时内嵌 `zrpc.RpcServerConf` 并声明 `Redis yaml:"redis"` 字段。go-zero v1.7.2 的 `RpcServerConf` 自带 `Redis` 字段，配置加载器在**结构体层级**就检测到 `redis` 键冲突：

```text
error: config file ... conflict key redis, pay attention to anonymous fields
```

与 yaml 内容无关（项目自带 `rpc/ordersvc/etc/ordersvc.yaml` 同样报错）。需要模块四调整 ordersvc 配置结构（例如去掉自定义 `Redis` 字段或改键名），之后后台 `POST /orders/{id}/cancel` 才能端到端联调。

### 5.2 远程库缺少两张表

`scripts/sql/migrate/07_admin_operation_business.sql` 定义的 `admin_coupon_issue_task`、`risk_blacklist_hit_record` 尚未应用到远程 `xiaolong_ridy` 库，导致发券任务列表、发券、风控命中记录三个接口返回 500。需要确认后执行该迁移文件（涉及远程共享库结构变更，未在本轮测试中擅自执行）。

### 5.3 文档不一致

`docs/admin/管理后台运营业务表与基础接口说明.md` 写优惠券状态 `2=停用`，但接口文档与代码实际为 `3=停用`（`DisableCoupon` 写 3，`validateCouponRequest` 允许 1-3）。建议统一文档口径。
