# 管理后台 P0 修复说明

## 管理员注册越权防护

`RegisterLogic` 在系统已有管理员时，必须从 gRPC metadata 中验证管理员会话。服务端校验会话管理员 ID 与请求 `operator_admin_id` 一致，且要求管理员角色为超级管理员；任一条件不满足均返回 `PermissionDenied`。

新增 `registerlogic_test.go` 覆盖合法超级管理员、非超级管理员、伪造操作者 ID、缺失操作者四种情况，防止客户端伪造操作者身份绕过权限控制。

## ordersvc 取消订单配置核验

新增 `rpc/ordersvc/internal/config/config_test.go`，加载生产同结构的 `ordersvc.yaml` 并校验 RPC、MySQL、Redis 必填配置。当前 `redisconf` 是 ordersvc 的命名字段，与嵌入的 go-zero `RpcServerConf` 不冲突；该测试通过，未能复现配置解析冲突。

`adminsvc` 的取消订单单测持续校验下游请求含有 `operator_type=admin` 和请求管理员 ID。已在具备 MySQL、Redis、etcd 的本机环境完成真实跨服务联调：对预先确认不存在的正数订单 ID 调用 `adminsvc.CancelOrder`，最终返回 `NotFound`，证明请求已到达 ordersvc，未产生订单或状态流水变更。

## 远程运营表迁移

已执行 `07_admin_operation_business.sql` 的六张运营表迁移，并执行 `09_admin_export_audit_task.sql` 的 `admin_export_task`、`admin_audit_outbox` 两张表迁移，均完成索引核验。两个脚本只创建表和索引，未写入业务数据。
