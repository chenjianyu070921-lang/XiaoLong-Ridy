# 管理后台取消订单联调记录

## 联调环境

- Redis：`127.0.0.1:6379` 可连接。
- etcd：`127.0.0.1:2379` 可连接。
- ordersvc：`127.0.0.1:50051` 可连接。
- adminsvc：`127.0.0.1:8084` 可连接。

## 验证步骤

1. 使用已有管理员账号通过 adminsvc 登录，取得短期会话。
2. 对远程 `ride_order` 执行只读查询，确认订单 ID `900000001` 不存在。
3. 通过 adminsvc 调用 `CancelOrder`，请求含 `admin_id`、取消原因，并由服务端转为 `operator_type=admin`、`operator_id=admin_id` 转发给 ordersvc。
4. ordersvc 返回订单不存在，adminsvc 映射为 gRPC `NotFound`。
5. 调用退出接口清理临时会话。

## 结果

真实链路 `adminsvc -> ordersvc.CancelOrder` 已打通，返回 `NotFound`。由于订单 ID 经只读查询确认不存在，本次未更新 `ride_order`，也未写入订单状态流水。

认证过程会更新管理员最后登录时间并写入登录、退出操作日志，这是登录会话的预期副作用。
