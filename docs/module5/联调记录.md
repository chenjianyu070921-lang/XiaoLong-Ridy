## 二、链路图

```
CreatePayment（支付预下单）
  → 生成 payment_no，创建 payment 单（status=1 待支付）
  → 调 MockChannel 下单，回填 transaction_id + pay_params
NotifyPayment（模拟支付宝回调）
  → 验签（本地 keys 为空时降级 MockVerifier）
  → payment.status 1 → 2（支付成功），回填流水号 + 支付时间
  → 发 Kafka 事件 order.paid（失败仅记日志，不阻断）
  → 调 ordersvc.GetOrder 拿 driver_id
  → 触发 SettleOrder 生成 settlement 结算单
GetPayment（支付查询）
  → 按 payment_no 返回支付状态（status=2）
RefundPayment（退款）
  → 校验可退金额 → MockChannel 退款 → 回写 refund_amount
```

## 四、真实联调步骤

### 前置条件

1. 启动 MySQL 并执行建表 + seed：

```powershell
docker compose -f deploy/docker/infra.yml up -d mysql
# 建表：scripts/sql/migrate/05_trade_module.sql
# seed：scripts/sql/migrate/07_price_rule_seed.sql
```

2. 对齐 mysql 账号密码：
   - `rpc/paysvc/etc/paysvc.yaml` 默认 `root:root123`
   - `deploy/docker/infra.yml` 的 MySQL root 密码默认 `root`
   - **二选一改一致**（改 yaml 或改 compose 环境变量）

### 一键联调

```powershell
powershell -ExecutionPolicy Bypass -File scripts/e2e/run_pay_e2e.ps1
```

脚本自动：启动 paysvc → 跑 `pay_e2e_client.go`（直连 50054 跑全链路）→ 停止 paysvc。

### 手动联调（可选）

```bash
# 终端1：启动 paysvc
go run rpc/paysvc/paysvc.go -f rpc/paysvc/etc/paysvc.yaml

# 终端2：跑联调客户端
go run scripts/e2e/pay_e2e_client.go -target 127.0.0.1:50054 -order 1001 -amount 2500 -refund 1000
```

预期输出依次打印：payment_no / transaction_id / 回调 success / 查询 status=2 / 结算抽成 500 + 司机实收 2000 / 退款 refunded=1000。
