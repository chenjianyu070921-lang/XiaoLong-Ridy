### 重要技术发现
1. **goctl 1.9.2 有 `__proto` bug**：生成代码用 `__proto.xxx` 但 import 是 `proto`，编译失败。
   - 已升级 goctl 到 1.10.2，但 1.10.2 仍有此 bug（ordersvc 是 1.10.1 生成，正确）
   - 修复方法：手动把生成文件里的 `__proto.` 全部替换为 `proto.`
2. **proto 生成方式**：用 `make pricesvc-goctl` / `make paysvc-goctl`（Makefile 里已预置），不是手写 protoc
3. **ordersvc 有编译错误**（别人的 bug）：`service_context.go:23` 传 `time.Hour*1` 给 int 类型的 MaxLifeTime，编译不过。我的模块用 `int(time.Hour)` 规避。
4. **common/datasource/mysqlx.go** 的 `SetConnMaxLifetime(time.Duration(c.MaxLifeTime))` 语义是纳秒，MaxLifeTime 传 int(time.Hour) 表示 1 小时
5. **全量 `go build ./...` 会失败**，但都是别人模块问题：`api/driver` 缺 main、`ordersvc` 类型错误。我的模块独立编译通过。
