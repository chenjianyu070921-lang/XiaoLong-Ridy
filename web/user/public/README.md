# 静态资源文件

## 需要添加的图片资源

请将以下图片放置在 `public/` 目录下：

### 必需图片
1. **logo.png** - 应用Logo（已提供logo.svg作为替代）
   - 推荐尺寸: 200x200px
   - 格式: PNG (支持透明背景)
   - 用途: 启动页、浏览器图标等

2. **default-avatar.png** - 默认头像
   - 推荐尺寸: 100x100px
   - 格式: PNG
   - 用途: 用户默认头像、司机头像

3. **location-marker.png** - 地图定位标记
   - 推荐尺寸: 30x40px
   - 格式: PNG (支持透明背景)
   - 用途: 地图上的位置标记

4. **map-placeholder.png** - 地图占位图
   - 推荐尺寸: 375x400px
   - 格式: JPG/PNG
   - 用途: 页面地图区域背景

### 可选图片
- driver-avatar-*.png - 司机头像示例
- car-icons/*.png - 车型图标

## 图片获取方式

1. 从原型设计稿中导出
2. 使用在线图标库（如 iconfont）
3. 使用AI生成工具创建

## 注意事项

- 所有图片建议进行压缩优化以减小包体积
- PNG格式适合需要透明背景的图片
- JPG格式适合照片类图片
- 建议使用2x或3x图以保证高清屏显示效果
